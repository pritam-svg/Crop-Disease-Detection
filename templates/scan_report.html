05 · Method and limitations

The AgroVision prototype uses a trained YOLO object-detection model to identify supported classes in an uploaded image. The annotated output displays the predicted locations and labels. When available, EigenCAM visualizes model feature activation.

This report documents an automated image screening, not a laboratory or field-confirmed diagnosis. The system does not establish pathogen identity, crop-wide prevalence, disease severity, or treatment dosage. Agricultural decisions should be checked with a qualified local expert.
